This package is a full project overlay for the Electron station app.

Copy ALL included files/folders into the station project root, not only src.
Important files included:
- index.html
- src/
- main.cjs
- preload.cjs
- package.json
- forge.config.cjs
- vite.config.ts
- tsconfig.json
- REBUILD_STATION_APP.bat

Why this matters:
- npm run dev uses Vite live source.
- The Electron packaged app uses dist/ generated by npm run build.
- If index.html, src, main.cjs, or dist/out are stale, the packaged app can look like an older version.

After copying this overlay:
1. Close all Electron app windows.
2. Run REBUILD_STATION_APP.bat.
3. Open the fresh app from out/ocr-app-win32-x64/ocr-app.exe.
4. Confirm the header shows: GNM-HYBRID-2026-06-24.5

If the app does not show that build marker, you are opening an old shortcut or building from the wrong project folder.
